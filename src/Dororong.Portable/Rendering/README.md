# Current Windows motion port

Authority: accepted v0.1.3 candidate14, source checkpoint d061177. No redesign.
This is a single-render-thread API, like the Windows presenter. Stateful renderer
instances belong to their host; cached frames own immutable pixel buffers.

- `SnackRunFrames`, `SnackMouthFrame`, `BodyBreathingFrame`, `HuntEyes`,
  `HuntHeadSampling`, `HuntMotion`, `LocomotionPresentation`: source math from
  the corresponding Windows Controls files; only bitmap/affine dependencies
  are replaced. Current walking uses the gallop source's walking branch.
- `MotionRenderer`: current 8-level/32-phase gait selector, native-size output.
- `TrackingRenderer`: upright HuntRenderer branch; canonical body, bounded
  hidden neck, original eye field and single cubic head sampling. Windows-derived
  neck coverage replaces host vector rasterization. No global blur/sharpen pass.
- `UprightTracking`: outer310x200 proximity ellipse, head/eye enter/exit easing
  and source bridge. This is not yet the complete pounce/desktop arbiter.
- `SnackRenderer`: original run48-phase/8-level selection, jump frame timing,
  entry recovery, original-mouth three chews and2.16-second happy sway. Only
  opening/tongue/jewel/drool coverage uses a derived Windows atlas. Shared Core SnackSession
  retains fixed launch trajectory, cancellation and eating ownership.
- `JumpBank`: native96px output from the accepted Windows HuntRenderer for all
 157 discrete frames. Production already chooses integer frames. The baked bank
  preserves its working-surface joins and outline finish exactly; it is not the
  old sitting/walking bank and is not a new drawing or interpolated replacement.

## Hunting, rest and head drag

`HuntingSession`, `PounceSession`, `HeadSwingSession`, `SurroundingPullMotion`,
head-only `SurroundingPullRenderer`, `HeadRecoveryFrame` and its anatomical mesh
retain the Windows math. `HuntingPresentation`, `RestPresentation` and the
head-only distance owner adapt presenter arbitration without changing Core.
Sleep resources and LOCO sit/rise frames are linked from the Windows assets.
The articulated renderer retains the original256px body layers, head matrix and
outline pass. Native reduction averages each2x2 footprint with half-up rounding,
not banker's rounding. Affine sampling uses8-bit fractional coordinates matching
the Windows reference. Neck coverage is sampled every0.00025radian and interpolated;
the displayed head and eyes remain continuous, not snapped to atlas frames.

## Derived coverage refinement

`hunt-joins.bin` (JOIN v3) stores only cropped hidden neck/shoulder patches.
Runtime decodes32 samples at a time with an8-block bounded cache, not thousands
of patches whenever a pose changes. `snack-effects.bin` (EFCT v3) stores only
transparent effects: drool at0.01-pixel intervals for the existing finite
head/bob transforms; mouth/jewel at10-microsecond intervals during the bite.
The finer bite interval preserves the Windows jewel resampler's sharp changes.
Effect decoding also uses32-sample blocks and an8-block cache, including both
blocks at interpolation boundaries. The old v2 entire48001-sample eating group
caused a synchronous stall; v3 preserves all284190 patch records byte-for-byte.
No character repaint, extra scaling, timing change or interpolation of whole
poses was introduced. Each bank pins the accepted reference DLL hash above.

Rebuild to NEW scratch files, then repack/compare before replacing assets:

```powershell
dotnet run --project tools/mac-render-assets/Export.csproj -c Release -- artifacts/macos/NEW-joins-v2.bin --joins
python -B tools/mac-render-assets/pack_atlas.py artifacts/macos/NEW-joins-v2.bin artifacts/macos/NEW-joins-v3.bin
dotnet run --project tools/mac-render-assets/Export.csproj -c Release -- artifacts/macos/NEW-effects-v2.bin --effects
python -B tools/mac-render-assets/pack_effects.py artifacts/macos/NEW-effects-v2.bin artifacts/macos/NEW-effects-v3.bin --report artifacts/macos/NEW-effects-reblock.json
```

The join exporter verifies its extracted geometry against the pinned binary at
three rolls for every frame. Repacking verifies all439,757 patches byte-for-byte.
These scratch exports stream output and may be partial after failure; never
install a partial bank. Runtime validates version/count/bounds/decoded length.
Original character/IP notices apply to all derived coverage.
Current hashes, reference comparison, native1x/integer4x proof and remaining
limits are in [the refinement record](../../../TASKS.md#macos-rendering-and-pet-only-launch--2026-10-15).
