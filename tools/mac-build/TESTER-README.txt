도로롱 Mac test13 · Apple Silicon · macOS 13 이상

2026-10-30 앉은 상태에서 서 있는 그림이 잠깐 끼어드는 문제를 수정한 테스트 앱입니다.
창 정보 조회가 잠시 끊겨도 지지 상태가 유지되면 앉기·앞발 반응을 유지합니다.
실제로 지지 창이 사라져 떨어지는 기존 동작은 유지합니다.
수락한 리본 옆 픽셀·접힘선 연결 수정도 포함합니다.
리본 밖의 검은 돌출을 제거하고, 안쪽 사선을 테두리까지 이어 연결했습니다.
앞서 수락한 기지개 앞발·탕탕 어깨 연결과 동작 속도는 유지했습니다.
앉은 앞발 터치·약한 몸 털기, 기지개·그루밍·간식 더 달라는 반응,
쥬얼 약올리기 1~6단계와 식후 웃음, 1분마다 DORO?·3분 뒤 잠들기를 포함합니다.
기존 맥 슬라이더 테마·화면 경계·착지 계산·부분 렌더링 수정은 유지했습니다.
Windows 호스트의 프레임/동작 검사는 실제 M2 실행 검증을 대신하지 않습니다.
실제 Mac 실행·CPU·메모리·Retina·외장/클램쉘·착지 부드러움은 미확인입니다.

실행
1. 기존 도로롱을 메뉴에서 종료합니다.
2. ZIP을 Finder로 풀고 Doro Mac Test.app을 응용 프로그램 폴더로 옮깁니다.
3. .app을 더블클릭합니다. .command 파일은 실행하지 않아도 됩니다.
   .NET·Rosetta·터미널 명령 설치가 필요하지 않습니다. 설정은 유지됩니다.
4. 종료: 캐릭터 우클릭 또는 메뉴 막대 머리 아이콘 → 종료.

이번에 확인할 것
- 앉아 상태에서 마우스를 가까이 가져가거나 좌우로 옮길 때 서 있는 그림이 끼어들지 않는지.
- 기지개의 앞발·몸통 구분과 탕탕 어깨 연결이 100~150%에서 자연스러운지.
- 앉은 채 앞쪽 마우스에 앞발을 뻗는지, 몸 클릭은 약하게 털고 연타에는 쿨타임이 있는지.
- 그루밍의 팔/머리 경계, 기지개, 쥬얼 뺏기와 식후 웃음이 자연스러운지.
- 조작 없이 1분 뒤 DORO?가 나타나는지. 자동 눕기 ON은 3분 뒤 잠들고 OFF는 질문을 반복하는지.
- 우클릭·메뉴 막대 슬라이더 100~150% 조절, 닫기·다시 열기, 머리 놓기·착지.
- 같은 크기에서 평상시와 조작 중 CPU·메모리가 계속 누적되는지. 로그 제출은 필요 없습니다.
