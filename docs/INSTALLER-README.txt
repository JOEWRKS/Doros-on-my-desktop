도로롱이 내 컴에?! / Doro's on my desktop?!
0.1.3 Preview · Windows x64 · 로컬 검증본 / Local test build

설치 / Install
1. 실행 중인 도로롱이 있다면 트레이 메뉴에서 종료하세요.
   Exit any running Doro through its tray menu.
2. Doros-on-my-desktop-Setup-0.1.3-win-x64.exe를 실행하세요.
   Run the Setup EXE. No administrator rights or separate .NET installation needed.
3. 시작 메뉴의 '도로롱이 내 컴에!'에서 실행하세요.
   Launch '도로롱이 내 컴에!' from the Start menu.

사용 / Controls
머리 드래그: 이동 / 볼 드래그: 늘이기 / 가까운 마우스: 추적·도약
Drag head to move; pull cheek to stretch; nearby pointer triggers tracking/pouncing.
캐릭터 우클릭 또는 트레이 좌·우클릭으로 메뉴를 엽니다.
Right-click the pet or left/right-click the tray icon to open the menu.
'간식 주기': 주얼을 따라 달립니다. 입 앞에서 잠깐 멈추면 먹습니다.
'간식 취소'로 중단. 'Windows 로그인 시 실행'은 선택 사항이며 기본 꺼짐입니다.
Choose '간식 주기' to start; hold the jewel near the mouth to feed; '간식 취소' cancels.
'Windows 로그인 시 실행' enables optional login startup (off by default).
'자동 눕기': 자동 수면만 끄고 켭니다. 기본 켜짐이며 재실행 후에도 설정을 기억합니다.
'자동 눕기' toggles automatic sleep only (on by default, saved across restarts).
제거는 Windows 앱 목록에서 / Uninstall from Windows' app list.
