# r101 — size slider, bounded implementation and candidate execution

## Authority and scope

User: “ㅇㅇ 통과. 이제 문제 없으면 사이즈 슬라이더”.
This accepts r100's selected fringe/closed-eye line correction, not a new
universal memory/performance acceptance. Add one compact size row to the
existing B2 character and tray menus; do not redesign the menu.

Range uses the existing renderer's supported 100–150%, in 1% steps.
Native Slider keyboard/automation behavior is retained. Value changes coalesce
for 100ms and flush on release/dismissal. Only successfully applied changes
are persisted on dismissal, in HKCU Preferences/SizePercent. Existing settings
are not rewritten. Saved size takes precedence over the local launch scale.
Legacy no-argument/no-saved-size rendering is not silently migrated: that path
does not expose this high-resolution slider. The accepted candidate uses the
existing explicit high-resolution launch option.

Capturing, falling, landing, lifting, perching and active snacks disable resize.
Reopen the menu after the activity ends. Resizing while supported re-renders at
source quality, compensates the world foot-center/sole, and bounds the resulting
visible footprint to the current monitor. No motion durations, speeds, artwork,
body-line normalization or r100 closed-ink definitions changed.

## Implementation

- Product/PetSizeMenuItem.cs: shared native slider row, current percentage,
  pending-update coalescing, busy-state handling, save-on-dismissal.
- Product/PetSizePreferences.cs: optional validated integer, changed-value write,
  readback/error handling. Real registry writes only follow user size changes.
- MainWindow + StyledTrayMenuBridge: connect both menu routes and saved size.
- Controls/DororongPresenter.Size.cs, HighResolutionGrab: resize canvas and raster;
  bypass the hunting-frame early return for a required size redraw; discard
  old-size frame/contact entries. Existing bounded locomotion cache unchanged.
- PetLoop + PetLoopHost + PetPlatformRuntime + PetWindowViewport: size eligibility,
  zero-time presentation, foot anchor, visible monitor bounds and native gutter.
- Scoped product/runtime tests and tools/SizeSliderProbe.
