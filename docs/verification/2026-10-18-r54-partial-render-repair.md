# r54 — 렌더 누락 보완, 전체 미완료

## 현재 판정

사용자의 r53 반려와 “제발 제대로 해” 지시에 따른 수정이다. **실행본 교체·시각 통과·전체 이식 완료가 아니다.** 볼 최대 당김은 기존 표정/윤곽과 차이가 남는다. 실패 후보를 설치하거나 새 테스트 앱을 켜지 않았다. r53 실패 근거는 [기존 원장](2026-10-18-r53-hover-cheek-rejected.md)에 유지한다.

## 실제 변경

- 사냥 몸 생성에 기존 `gaze-compose.js.drawForelegs`의 두 앞발/배 윤곽 처리를 원화 해상도로 옮겼다. `hunt-forebody.cjs`가 파츠 위에 겹발을 덧붙이지 않고 해당 앞몸 영역을 교체한다. `HighResolutionHuntNeck`는 기존 연결점을 이용해 몸·머리 뒤의 목을 연결한다.
- 기존 `RenderHighResolutionGrab`은 일반 걷기·앉기 등에서 false를 반환해 구형 `RenderPose`로 넘어갔다. 걷기/앉기/일어서기에는 기존 고해상도 파츠를 읽는 322항목 지연 로딩 bank를 추가했다. 1개는 감은 머리, 256개는 걷기 몸, 65개는 앉기 몸이다. 기존 이동 거리/보행 진폭/앉기·일어서기 시간과 깜박임 시계를 연결했다. 머리 이동값은 클릭 좌표 변환에도 포함한다.
- 감은 머리는 승인된 표정에 r33 마스크의 공통 영역 변경만 옮긴 파생 데이터다. 표정과 마스크 변경이 겹치면 생성기가 실패한다. 원화 PNG나 기존 grab bank는 수정하지 않았다.
- 볼 v1/v2/v3에서 선택 영역·근처 눈/입 이동·윤곽 샘플링을 비교했다. 기존 좌표의 부분적인 재사용과 단순 변형장만으로 기존 합성을 대체할 수 없었다. v3에도 근처 눈과 볼 선 차이가 남으므로 **진단 후보이며 채택/완료본이 아니다.** 이 코드가 있는 opt-in 경로를 배포하면 안 된다.
- 후속 v4/v5는 원화의 실제 눈 선 범위를 확인해 선택 경계를 수정했다. v6의 별도 볼 선 보정은 충분한 개선을 확인하지 못해 런타임에서 제거했다. 실험 소스는 `v6/HighResolutionCheekOutline.cs`에 보존했다. 현재 선택은 v5 계열 진단 코드이며 볼의 시각 통과 판정은 여전히 없다.

- 사냥 19개 시트를 직접 열었다. 1배/1.5배 각각 0~156 전체 정수 프레임, 1.125/1.25/1.375배 각각 14개 시점, 총 356개 저장 슬롯이다. 이 중립 시선 표본에서는 반려된 작은 별도 앞발 돌기가 보이지 않고 앞발 두 개가 앞으로 이어진다. 기존 제품의 아래쪽 윤곽을 나란히 넣었다. 새 얼굴/몸 원화가 기존 96px 제품과 모든 픽셀이 같다는 뜻은 아니다.
- 걷기·멈춤·앉기·일어서기·시계 진행 15개 시트를 직접 열었다. 1/1.25/1.5배 각각 93개, 총 279개 저장 슬롯이다. 동일한 머리와 파츠 기반 몸이 유지된다. 감은 눈은 앉기 46~50번 슬롯에서 보인다. 뒤쪽 `blink`라는 파일 이름의 표본에는 두 번째 눈 감기가 없으므로 파일 이름만으로 깜박임 검수를 주장하지 않는다.
- 볼 v1/v2/v3 최대 당김 및 v3 0/2/4/8/12/16/20/-5 비교 시트를 직접 봤다. `v3/cheek-detail.png`의 왼쪽은 기존 실제 렌더, 오른쪽은 후보다. 근처 눈/선 차이가 남아 통과하지 않았다.

- 위 총 635개는 저장 슬롯 수다. 고유 이미지 수 또는 실제 마우스로 조작한 프레임 수가 아니다. 전 각도·모든 중간 시간·실시간 재생을 검수했다는 의미도 아니다.

## 미완 / 다음

1. 볼은 원화의 실제 눈/입/볼 선 선택과 기존 합성 순서를 더 맞춰야 한다. 이번 후보는 사용자의 수락을 받지 않았으며 자체 시각 통과도 아니다.
2. 수면/깨우기, 간식/식후 반응, 매달리기 및 다른 직접 상호작용은 여전히 구형 경로가 남는다. 걷기/앉기 보완이 모든 구형 이미지 전환을 해소하지 않는다.
   또한 `CreateHighResolutionPress`는 선택 볼/윗머리가 아니면 null을 반환한다. 따라서 고해상도 이미지에서 몸 클릭은 구형 경로로 전환되는 것조차 아니라 입력 대상이 누락된다. 머리/볼 입력 검사를 전체 클릭 지원으로 확대하면 안 된다.
3. 새 걷기/앉기에서 잡기 시작·몸 자세 전환·놓기 전체의 외형 연속성은 미완이다. 앉은 머리의 입력 좌표 검사가 전체 진입 모션 검사를 대신하지 않는다. 호기심/놀람/몸 숨쉬기 역시 고해상도 경로의 기존 행동 보존 대조가 필요하다.
4. 실제 마우스 조작, 실행 성능, 전체 회전/중간 프레임 검증은 미완이다. 먼저 위 결함을 수정하고 그 뒤 실제 앱 검증을 진행한다. 이 상태의 설치본/기본 실행 교체는 하지 않는다.

원화·기존 제품 결정·완료 기준은 유지한다. 설치본, Mac, commit/push는 변경하지 않았다.
