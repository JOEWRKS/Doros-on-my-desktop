# 쥬얼 회수 표정 · 사용자 이미지 두 단계 반영

## 승인 및 범위

사용자는 첫 첨부 그림의 뜬 눈·화난 눈썹·빨간 화남 표시를 지정했고,
추가 그림은 세 번 연속 뺏었을 때 사용하도록 요청했다. 이전 후보의 감은 `><`
눈 표정만 이 결정으로 대체한다. 원화 파일, 기존 머리/몸 실루엣, 이동·반응 속도는
변경하지 않는다. 입에 .5초 유지하면 먹기 확정, 회수 반응 .9초도 그대로다.

1·2회는 기울어진 눈썹과 화남 표시 하나, 3회 이상은 표시 두 개와 찌푸린 입이다.
연속 횟수는 현재 간식 세션 안에서만 3까지 저장한다. 먹기 확정 또는 간식 취소/
새 시작/입력 유실 시 초기화한다. 반응 중 움직임·단순 통과는 횟수를 올리지 않는다.
이 초기화 정책은 작업 중 사용자에게 알렸으며 별도 사용자 수락을 주장하지 않는다.

## 구현

- Core SnackPose.WithdrawalStreak → Windows/Mac 공유 high-resolution Face.Furious 연결.
- 고해상도 원래 뜬 눈 소스를 복사하고 눈썹/표시만 합성한다. 세 번째 표정에만
  기존 입의 국소 footprint를 같은 행 피부색으로 치우고 찌푸린 입을 그린다.
- 표정 버퍼는 이전 후보와 같은 225×225×4 float 한 개(810,000B)다. 두 단계 전환 때
  같은 버퍼를 원본부터 재작성하고 ink 캐시를 무효화한다. 크기·횟수별 캐시 추가 없음.
- 원화/Assets, 물리, 먹기 확정 후 씹기 시간, 추적 속도, 슬라이더 수정 없음.
- 기존 96px legacy preview는 이전의 감은 눈 흔들기 경로다. 이번 표정은 실제 제품의
  high-resolution Windows/Mac 경로에 적용했으며 legacy 외형 동등성을 주장하지 않는다.
