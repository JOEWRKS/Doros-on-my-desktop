## Confirmed redundant work and narrow fixes

1. `Presenter.MeasurePlatformGeometry` rescanned all active alpha pixels on every
   read even when the raster and offsets were identical. At150%/density2,1000
   same-frame reads cost roughly415–430ms on this Windows x64 host. Keep one
   nullable geometry result keyed by revision, extent, size, recoil and release
   offset. No pose/frame cache, new image bank, threshold or contact formula.
2. Raw Mac frames went scratch → retained array → native bitmap. `OwnedFrame.cs`
   invokes the unchanged shared sampler directly into the retained array, restoring
   the separate scratch in `finally`. Sole queries cannot overwrite display-owned
   bytes. No resampling change or added memory pool. Removes one full active-frame
   copy (2,359,296 bytes at150%/density2) per newly rendered frame.
3. At maximum active width the bitmap stride matches the source, but upload still
   made one Marshal.Copy per row. Now one contiguous copy, with the original row
   copy fallback for padded stride. Identical source bytes and destination padding.
4. Normal ticks called NSWindow move/click-through setters even for identical
   values, hid an already-hidden jewel overlay, and formatted an unattached
   diagnostics label. Bounded per-overlay state suppresses identical setters;
   changed values apply immediately. Cocoa coordinates include primary-display
   height; display-layout/DPI changes and jewel show invalidate position state.
   Normal label formatting is omitted; diagnostics retain it. Real AppKit cost
   saved and Spaces/reconfiguration behavior still require native checking.

Timer16ms, Core, motion curves, sampler arithmetic, source artwork, active
resolution/density, hit thresholds, slider range/debounce, speed and Windows files
are unchanged. Monitor/pointer polling and scene refresh cadence are unchanged.
Animated breathing still renders at its existing cadence; no FPS/quality reduction.
