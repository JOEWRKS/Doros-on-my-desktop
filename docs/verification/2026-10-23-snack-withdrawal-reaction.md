# 쥬얼 회수 반응 — 2026-10-23

## 이번 사용자 승인

사용자가 쥬얼을 입에 댔다가 뺏으면 화내는 반응을 우선 구현하도록 요청했다.
이후 **먹기 전 대기를 0.5초**로 지정하고 그 전에 뺏으면 화내는 조건을 선택했다.
앞서 제안한 짧은 찡그림·고개 흔들기 후 다시 쫓는 흐름을 구현했다.
다른 아이들 포즈, 대사/꿈 풍선, 와다다, 체중/배고픔 시스템은 이번 범위가 아니다.

## 구현

- `SnackSession.OfferSeconds=.5`: 기존 .16초 정지 감지 + .24초 먹기 누적을
  총 .5초의 입 근처 정지 누적으로 교체했다. 실제 씹기1.7초·행복·정리 시간은 그대로다.
- 단순 통과를 구분하기 위해 입 근처80ms 정지 후 제안한 간식으로 인식한다.
  기존 입 허용 범위19×17 DIP는 유지한다. 커서 누적 이동이1 DIP를 넘으면
  먹기 대기를 다시 세므로, 천천히 빼는 동안 먼저 먹어버리지 않는다.
- 먹기 확정 전 커서를 입 범위 밖으로 빼면 `Angry`를 한 번 시작한다.
  캐릭터/크기 변화만으로 입 위치가 바뀌고 커서는 그대로인 경우는 회수로 보지 않는다.
- 약 .9초간 제자리에 서서 눈을 찡그리고 최대3도 고개를 흔든다. 작은 화남 표시를
  추가했다. 쥬얼은 계속 커서에 표시되며, 반응 후 같은 간식 쫓기로 돌아간다.
  다시 .5초 두면 먹는다. 이미 먹기 확정된 뒤 커서를 옮겨도 화내지 않는다.
- 취소/입력 유실/긴 중단은 기존처럼 간식을 취소하고 상태를 지운다.
- `HighResolutionGrabRaster.Angry.cs`는 기존 닫힌 눈 소스를 복제한 고정225px
  배열1개만 보유한다(810,000bytes). 새 얼굴은 반응 동안만 사용하며 원화 파일이나
  기존 열린/닫힌 눈 버퍼는 수정하지 않는다. 시간·배율별 이미지 캐시를 만들지 않는다.
- Windows와 Mac 공통 상태 및 각 현재 고해상도 presenter/cursor 경로를 연결했다.
  구형96px 렌더러는 닫힌 눈+같은 고개 흔들기로 안전하게 처리하며, 새 찡그림/화남
  표시는 현재 고해상도 경로에서 제공한다. 구형 미리보기와의 표정 동일성은 주장하지 않는다.
- 이 브랜치에 없던, 이미 별도 Windows release worktree에서 적용한 `크기` 제목의
  Ideal 텍스트 포맷1줄을 가져와 이번 후보가 그 수정을 되돌리지 않도록 했다.
  슬라이더나 설정 정책은 변경하지 않았다.
