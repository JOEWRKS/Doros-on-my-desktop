# r85 — exact sole-band work reduction

## Scope and cause

Preserve accepted art, shape, animation clock, unfolding curve and snack speed. No installation or settings changes. The r84 real clip had a 32.29 ms CPU output gap from contact to first spread; first-spread work was 17.24 ms, including 10.13 ms sole work. These are CPU timings, not monitor presentation timestamps.

Sparse sole sampling previously processed eight rows at a time. Once the lowest occupied row was found, that batch could still include up to seven unnecessary rows above the two-DIP contact band. Those rows can take 64 subpixel samples per pixel. Replace the batch with descending individual rows, stopping exactly when the remaining rows contribute no area to the contact band. Samples, alpha threshold, transforms and contact-band width are unchanged. Hoist the existing row-invariant coverage calculation outside the pixel loop. No animation time advance or skipped starting frame (the rejected r83 approach) is reintroduced.
