## 원인과 변경

1. `PetPlatformRuntime.TryBeginPerch`가 carryReleased=false인 Idle/Walk에서도 창 전체 GroupBy/ToDictionary/발판 계산을 먼저 수행했다. 실제 `EdgePerchRuntime.TryBegin`의 거절 조건을 외부에서 먼저 검사한다. 조기 반환 때 기존과 같이 한 프레임짜리 readiness를 지워 오래된 준비 표시가 남지 않도록 한다. 기존 scene health 선행 조건은 유지한다.
2. 동일한80ms desktop snapshot을 매 animation tick마다 논리좌표로 복사했다. source가 발행하는 immutable snapshot 참조와 정확한 좌표 map이 둘 다 같을 때만 변환을 재사용한다. revision만으로 재사용하지 않는다. 새 scene/실제 DPI/좌표 map 변경은 다시 변환한다. monitor 복사도 같은 snapshot에서 반복하지 않는다. 실제 presenter map/위치 샘플링과 scene freshness/실패/만료 검사는 매 tick 유지한다.
3. perch 발판은 동일 logical scene에서 재사용하고,일반 발판은 동일 scene+정확한 bodyHeight에서만 재사용한다. 상한 없는 history cache를 추가하지 않는다. `PlatformGeometry` 알고리즘/Core DLL은 바꾸지 않는다. 창 이동·가림·모니터 교체·몸 높이 변경은 기존 알고리즘으로 재계산한다.
4. sparse sole의8줄 이하 작업에5개 worker를 깨우고 countdown 대기하던 경로를 caller의 순차 실행으로 바꾼다. 더 큰 표시 raster는 기존 병렬 처리 유지. 각 픽셀 샘플 순서/원화/품질/시뮬레이션 시계는 그대로다. serial 경로까지 C# captured locals가 할당되지 않도록 parallel helper를 분리한다.

## 판정과 남은 작업

**확인된 중복 계산/반복 할당 경로 수정 및 보행 사용자 확인은 완료. 전체 렉/메모리 누수 해결은 미완.** 원화·형태·속도 유지,550개 회귀/420개 원시 픽셀 동일/실제300초 기록을 확인했지만 50ms초과tick32회가 남았다. 기존 r79 사용자 착지 개선 확인을 r80 전체 수락으로 이전하지 않는다.
