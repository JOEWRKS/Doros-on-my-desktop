## 승인과 변경

- 사용자 “통과”로 앞쪽 기울기를 수락했다. 그 그림/각도/모션/말풍선은
  그대로 두고, 최초90초·1회 표시를 최초60초·60초 간격 반복으로 교체했다.
- 자동 눕기OFF:60/120/180/...초에 기존 짧은 보행→갸웃/DORO?를 반복한다.
- 자동 눕기ON:60/120초 반응 후180초에는 수면을 우선한다. 자율 보행이나
  질문 중이어도 수면 기한이 되면 질문 상태를 정리하고 기존 수면으로 전환한다.
  이 우선순위는 질문 기능을 사용하는 호스트에만 적용한다.
- 간격은 반응 시작 기준이다. 보행/질문 시간을 매번60초에 더하지 않는다.
  직접 조작은 두 타이머를 초기화한다. 옵션 변경 시 초기화/깨우기는 기존 정책 유지.
- 공중/매달림/수동 앉기 등 자율 동작 정지 중에는 기존처럼 시계가 정지한다.
  전역 키보드 유휴 측정이나 벽시계 catch-up을 새로 추가하지 않는다.
- Windows 연결값과 Core 예약/우선순위만 변경했다. 수락한 renderer/원화/
  기울기 sampler/보행 속도/말풍선 구현은 이번 작업에서 수정하지 않았다.
