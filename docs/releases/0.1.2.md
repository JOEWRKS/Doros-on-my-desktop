# 도로롱이 내 컴에?! / Doro's on my desktop?! — 0.1.2 Preview

## 설치 · Install

**[Windows 설치 파일 받기 / Download Windows installer](https://github.com/JOEWRKS/Doros-on-my-desktop/releases/download/v0.1.2/Doros-on-my-desktop-Setup-0.1.2-win-x64.exe)**

기존 도로롱을 트레이에서 종료한 뒤 설치 파일을 실행하세요. 설치 후 시작 메뉴의 **도로롱이 내 컴에!**에서 실행합니다.

Exit the existing pet through its tray, run the installer, then launch **도로롱이 내 컴에!** from the Start menu.

Windows x64 · 관리자 권한 불필요 · .NET 8.0.31 포함 / Per-user installation · .NET 8.0.31 included.

**Source code (zip/tar.gz)는 설치 파일이 아닙니다. / Source-code archives are not installers.**

## 주의 · Limitations

이번 버전은 코드 서명을 생략한 **미리보기**입니다. Windows에서 게시자/SmartScreen 경고가 표시될 수 있습니다. 보안 기능을 끄지 마세요. 깨끗한 PC·혼합 DPI 검증은 남아 있으며, 앞선 0.1.1의 설치·제거 검증을 0.1.2 실기기 업데이트 검증으로 간주하지 않습니다.

This **unsigned preview** may trigger publisher/SmartScreen warnings; do not disable security checks. Clean-machine and mixed-DPI acceptance remain incomplete. The earlier 0.1.1 host lifecycle test is not a 0.1.2 host-upgrade test.

An unofficial, non-commercial fan-made derivative of the NIKKE-derived Dororong (Doro) character. MIT applies to original code, not character art, derived assets, names or trademarks. Original fan-artist and asset distribution permissions remain unverified.
