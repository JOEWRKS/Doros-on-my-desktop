## 설치·사용 · Install & use

기존 앱을 트레이에서 종료 → 설치 → 시작 메뉴의 **도로롱이 내 컴에!** 실행. 머리 드래그로 이동, 볼 당기기, 마우스 추적·도약, 창·작업표시줄 매달리기를 지원합니다. 트레이 우클릭으로 로그 열기·종료.
Exit the existing pet → install → launch **도로롱이 내 컴에!** from Start. Drag the head, pull cheeks, attract attention/pounces and hang from window/taskbar edges. Right-click the tray for logs or Exit.

**Source code ZIP은 설치 파일이 아닙니다. / Source-code ZIPs are not installers.**
