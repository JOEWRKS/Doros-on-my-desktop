# Mac r104 test02 — Apple Silicon 테스트용

[바로 다운로드 (ZIP, 약 99MB)](https://github.com/JOEWRKS/Doros-on-my-desktop/releases/download/macos-r104-test02/Doro-Mac-arm64-r104-test02.zip)

Apple Silicon(M1 이상), macOS 13 이상. .NET·Rosetta 별도 설치 불필요.
실제 Mac 실행·Retina 입력·성능·메모리는 **미검증**입니다.
Developer ID 서명과 Apple 공증이 없는 테스트판입니다.

## 옮겨서 실행

1. 맥북에서 ZIP을 직접 받거나, ZIP 그대로 USB/클라우드로 옮깁니다.
2. 기존 테스트 앱이 있으면 종료합니다. Finder에서 ZIP을 풀고
   **Doro Mac Test.app**을 **응용 프로그램** 폴더로 옮깁니다.
3. 앱을 더블클릭합니다. 메뉴 막대 머리 아이콘 또는 캐릭터 우클릭 → 종료.

개발자 확인 경고로 막히면 출처를 신뢰할 때만 실행을 한 번 시도한 뒤
시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**를 사용합니다.
[Apple 공식 안내](https://support.apple.com/ko-kr/102445).
손상됨/컴퓨터 손상 경고라면 중단하고 문구를 보내주세요. 보안 기능을 끄거나
격리 속성을 삭제하는 명령을 사용하지 마세요.

## 필수 확인

- 실행·종료·재실행이 되고, 중복 실행해도 한 마리인지.
- 걷기·앉기 추적, 간식 먹기에서 눈·목 연결·침 경계가 깨지지 않는지.
- 머리 흔들기→놓기·착지, 볼 당김→놓기, 일반 창 매달리기·앞발 당김이 정상인지.
- 크기 100↔150% 왕복 시 끊김·화질·발/클릭 위치 문제가 없는지, 재실행 후 크기가 유지되는지.

Dock에는 매달리지 않고 화면 맨 아래에서 걷도록 되어 있습니다.
자동 로그인 실행이나 추가 권한 설정은 이번 첫 확인에 필요하지 않습니다.
실패하면 macOS 버전·한 동작의 재현 순서·경고/화면을 알려주세요.
