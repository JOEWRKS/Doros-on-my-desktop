## 실행

1. 기존 도로롱을 메뉴 → 종료합니다.
2. ZIP을 풀고 `Doro Mac Test.app`을 응용 프로그램에 옮겨 기존 테스트 앱을 교체합니다.
3. 앱을 더블클릭합니다. `화면 경계 진단.command`는 평소 실행에 필요 없습니다.
4. 보안 경고로 실행이 막히면 경고 문구를 보내주세요. 보안 기능을 끄지 않습니다.

## 이번에 확인할 것

- 내장 화면: 머리를 잡아 화면 위쪽으로 이동할 때, 상단 약 1/5에서 막히는지.
- 앱을 켠 채 클램쉘·외장 화면으로 전환: Finder/브라우저 창 윗변에 올라가는지, 창을 움직이면 따라오는지. 덮개를 다시 열었을 때도 위치가 정상인지.

두 항목의 결과만 알려주세요. CPU·메모리 장시간 검사를 다시 할 필요는 없습니다.
문제가 남으면 포함된 90초 경계 진단을 별도로 안내합니다.
