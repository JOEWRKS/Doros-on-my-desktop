# 도로롱이 내 컴에?! / Doro's on my desktop?! — 0.1.1 Preview

## 설치 · Install

**[Windows 설치 파일 받기 / Download Windows installer](https://github.com/JOEWRKS/Doros-on-my-desktop/releases/download/v0.1.1/Doros-on-my-desktop-Setup-0.1.1-win-x64.exe)**

1. `Doros-on-my-desktop-Setup-0.1.1-win-x64.exe`를 실행하세요. / Run the Setup EXE.
2. 설치 후 시작 메뉴에서 **도로롱이 내 컴에!**를 실행하세요. / Launch **도로롱이 내 컴에!** from the Start menu.
3. 업데이트 전에는 기존 도로롱을 트레이에서 종료하세요. / Exit the existing pet through its tray before updating.

Windows x64, 관리자 권한 불필요, .NET 런타임 포함. / Windows x64, per-user installation, .NET runtime included.

**Source code (zip/tar.gz)와 Code → Download ZIP은 설치 파일이 아닙니다. / Source-code archives are for developers, not for installing the app.**

## 변경 · Changes

- 새 이름을 앱·트레이·설치기·시작 메뉴·Windows 앱 목록에 적용했습니다. / Rebranded the app, tray, installer and Windows entries.
- 기존 설치·데이터 경로를 유지하고 0.1.0의 이전 바로가기를 교체합니다. / Preserves existing data and migrates the old 0.1.0 shortcut.
- 한영 사용 안내와 프로젝트·런타임 라이선스를 설치 폴더에 포함했습니다. / Includes a bilingual quick start and project/runtime notices.
- 기존 캐릭터 모션은 유지합니다. / Character behavior is unchanged.

검증 범위·해시: [release verification](../verification/2026-09-21-rebrand-release.md). Checksums are also attached as `SHA256SUMS.txt`.

## 주의 · Limitations

코드 서명이 없는 **미리보기** 버전입니다. Windows에서 알 수 없는 게시자 경고가 표시될 수 있습니다. 깨끗한 PC·혼합 DPI 등 모든 환경의 검증은 끝나지 않았습니다.

This **unsigned preview** may trigger a Windows publisher warning. Clean-machine and broader Windows/mixed-DPI acceptance remain incomplete.
