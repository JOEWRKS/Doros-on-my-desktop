# Mac r104 test04 — M2 테스트용

[바로 다운로드 — ZIP 약99MB](https://github.com/JOEWRKS/Doros-on-my-desktop/releases/download/macos-r104-test04/Doro-Mac-arm64-r104-test04.zip)

Apple Silicon(M1 이상), macOS13 이상. .NET/Rosetta 별도 설치 불필요.
Developer ID 서명·Apple 공증 없는 테스트판이며 실제 M2 실행/성능은 미검증입니다.
기존 test02 이후 중복 계산·복사·창 갱신을 줄이고 호흡/눈 이동의 변경 영역만
다시 계산합니다. 원화·화질·동작·속도·프레임 주기는 유지합니다.

## 실행

1. 기존 도로롱 Mac 앱을 메뉴 → 종료합니다. 동시에 여러 버전을 켜지 않습니다.
2. 맥에서 ZIP을 받고 Finder에서 압축을 풉니다.
3. `Doro Mac Test.app`을 응용 프로그램으로 옮긴 뒤 더블클릭합니다.
4. 종료는 캐릭터 우클릭 또는 메뉴 막대 머리 아이콘 → 종료입니다.

개발자 확인 경고가 나면 출처를 신뢰하는 경우에만 앱 실행을 한 번 시도한 뒤
시스템 설정 → 개인정보 보호 및 보안 → '확인 없이 열기'를 확인합니다.
[Apple 공식 안내](https://support.apple.com/ko-kr/102445).
손상/악성코드 경고라면 중단하고 문구를 보내주세요. 보안 기능을 끄거나 격리
속성을 지우지 않습니다. 최초 검사에는 자동 로그인 실행이나 추가 권한이 필요 없습니다.

## CPU 필수 확인

- 활성 상태 보기에서 `Doro` 또는 `Dororong`을 검색하고 해당 프로세스의 `% CPU`를 봅니다.
  화면 아래의 시스템 전체 CPU와 구분합니다.
- 실행2분 후, 이전 측정과 같은 화면/크기(가능하면150%)에서 평상시·걷기·앉기를
  각각30초 정도 관찰해 대략적인 CPU 범위를 적습니다. 다른 무거운 작업은 피합니다.
- 여전히 약100%가 지속되는지, 조작이 끝나도 CPU가 높은 상태로 남는지 알려주세요.
  숫자가 낮아도 눈 추적/볼 놓기/크기 변경에 잔선·잘림이 생기면 함께 알려주세요.

[프로세스 CPU·메모리 확인 방법 — Apple](https://support.apple.com/ko-kr/guide/activity-monitor/actmntr1001/mac).

## 메모리 필수 확인

동일 실행을 유지하고 아래 과정에서 해당 프로세스의 메모리 MB를 적습니다.

1. 실행 후5분: 기준값.
2. 100↔150% 슬라이더5왕복 + 머리 잡기/놓기5회 + 볼 당김/놓기5회 + 간식3회.
3. 조작 없이5분 기다린 값.
4. 2번을 한 번 더 반복하고 다시5분 기다린 값.
5. 앱을 켜둔 채30분 시점의 값.

첫 사용 때 한 번 오르는 것과, 같은 반복 후 쉬어도 계속 계단식으로 쌓이는 것을
구분합니다. 즉시 내려가지 않는다고 누수는 아닙니다. 전체 '메모리 압력'은 보조 지표이며
도로롱 단독 누수 판정값이 아닙니다.
[메모리 표시 설명 — Apple](https://support.apple.com/ko-kr/guide/activity-monitor/actmntr1004/mac).

회신: `macOS 버전 / 크기·화면 / 평상시·걷기·앉기 CPU 범위 /
메모리 기준→1차휴식→2차휴식→30분 / 잔선·잘림·끊김 유무`.
