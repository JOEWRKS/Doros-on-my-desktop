# 도로롱이 내 컴에?! · v0.1.3 Preview

## 설치 · Install

**[설치 파일 다운로드 · Download installer](https://github.com/JOEWRKS/Doros-on-my-desktop/releases/download/v0.1.3/Doros-on-my-desktop-Setup-0.1.3-win-x64.exe)**

Windows x64 · 약 66MB / About 66MB · .NET 포함 / Runtime included · 관리자 권한 불필요 / No admin required

실행 중인 도로롱을 트레이에서 종료한 뒤 Setup EXE를 실행하세요.
설치 마지막 화면에서 실행을 선택하거나 시작 메뉴의 **도로롱이 내 컴에!**에서 실행하면 됩니다.
Exit any running Doro through its tray, run the Setup EXE, then choose launch or use the Start menu.

**Source code ZIP은 설치 파일이 아닙니다. / Source-code ZIPs are not installers.**
`README.txt`는 사용 안내, `SHA256SUMS.txt`는 파일 확인용입니다.
`README.txt` contains instructions; `SHA256SUMS.txt` contains file checksums.
