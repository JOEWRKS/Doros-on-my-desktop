# 원본 윤곽 기반 앉기 재설계

상태: **결과 거절됨. 과거 ‘ㄱㄱ’를 현재 승인으로 해석하지 않는다.**
사용자의 최신 지시로 원본 이미지 절단을 허용했으며, 현재 정지 그림은
기본·앉은 원본의 픽셀을 그대로 분리·재조립한다. 아래 재드로잉 설계와
앉은 그림의 참고 전용 제한은 이전 시도의 기록이며 현재 구현 지시가 아니다.
실행·검증 원장은 [TASKS](../../../TASKS.md)다. 출시 단계는 변경하지 않는다.

## 목표와 첫 산출물

머리는 원본 그대로 두고 몸·다리는 원본 윤곽과 비율을 본떠 완성한다.
그 그림 안에 관절을 배치하여, 둥근 엉덩이를 유지하면서 앞다리는 곧게
지지하고 뒷발은 앞으로 뻗은 앉은 자세를 만든다. 녹거나 낮은 덩어리처럼
눌리는 몸, 길어진 발, 이중 외곽선, 몸에 묻힌 다리는 허용하지 않는다.

첫 구현 범위는 **기본 자세와 앉은 끝자세의 정지 비교**다. 동작 연결,
제품 프레임 뱅크 교체, 설치, 커밋·푸시·배포는 포함하지 않는다.
정지 자세를 사용자가 수락하기 전에는 움직임을 연결하지 않는다.

## 근거와 입력

- 기본 그림: `src/Dororong.App/Assets/dororong-canonical.png` (96×96).
- 앉은 참고: `tools/PreviewLocomotion/assets/seated-final-10-2.png`.
  비교·비율 계측에만 사용한다. 참고 PNG를 새 캐릭터의 몸이나 끝 프레임으로
  붙여 넣지 않는다. 원본 머리의 기준점으로 정렬하며 몸만 억지 확대하지 않는다.
- 이전 시도: `canonical-bind.cjs` / `canonical-sit.cjs`. 비교·실패 증거로 보존한다.
  현재 절단에는 원본 윗뒷다리 픽셀이 없고, 숨은 그림을 원본 alpha=255 영역으로
  잘라 자세 변경에 필요한 연결부를 잃었다. 기존 임의 관절 좌표·길이가 맞다는
  전제나 기본 자세 RGBA 일치만으로 새 그림의 정확성을 판정하지 않는다.

## 그림과 관절의 분리

1. **원본 계측**: 머리폭 대비 몸폭·엉덩이 높이, 각 다리의 굵기와 테이퍼,
   보이는 다리 길이, 실제 발바닥 끝과 가려진 어깨·고관절 위치를 구분한다.
   뼈 끝은 발바닥과 같은 점이라고 가정하지 않는다. 관절은 가려진 몸 안에
   둘 수 있지만 별도 발목/발끝 축을 추가하지 않는다.
2. **완성된 부위 그림**: 가슴·몸통·엉덩이, 양 앞다리, 보이는 뒷다리의
   윤곽을 원본에 맞춰 명시적인 곡선과 닫힌 면으로 만든다. 가려진 뿌리와
   허벅지도 실제 면을 갖는다. 임의 타원/캡슐을 캐릭터 몸으로 대체하지 않으며,
   새 그림을 원본 전체 이미지의 불투명 픽셀로 다시 잘라내지 않는다.
3. **자세 데이터**: 기본/앉은 자세의 어깨·골반·무릎·발 지점을 먼저 맞춘다.
   기존의 8px 골반 이동·13.5px 발 이동 수치를 정답처럼 재사용하지 않는다.
   다리 길이는 계측·보완한 그림에 맞춰 정하고, 자세를 맞추려고 그림 전체를
   비균일 확대·축소하지 않는다.
4. **윤곽 제어**: 관절 위치가 부위 그림의 기준점과 연결부 곡선을 제어한다.
   관절 주변의 작은 곡선 조정은 가능하지만 몸통 전체 축소, 이미지 모핑,
   전신 가중 변형, 알파 합집합 closing/erosion 또는 구멍 사후 메우기는 쓰지 않는다.
   나중 동작에서도 실제 자세가 그림을 결정해야 하며 시간별 이미지 섞기가 아니다.

이렇게 원본 계측, 부위 윤곽, 자세, 합성을 별도 데이터/모듈 책임으로 둔다.
첫 단계는 기존 Canvas 환경에서 격리된 로컬 도구로 구현하고 새 유료 도구나
엔진을 도입하지 않는다. 파일명·세부 실행 순서는 설계 승인 뒤 계획에서 정한다.

## 외곽선·가림 순서

- 머리/얼굴/머리카락/리본은 원본 텍스처 한 장을 유지한다. 크기 변형 없이
  위치·회전만 가능하며 기존 눈 모션이나 다른 기능은 이번 범위가 아니다.
- 뒤쪽 다리 → 몸통/엉덩이 → 가까운 뒷다리 → 가까운 앞다리 → 머리 순서를
  기본으로 한다. 원본에서 보이지 않는 반대편 뒷다리를 복제하지 않는다.
- 피부 면은 연결부에서 충분히 겹치되, 가려지는 뿌리의 선은 따로 숨긴다.
  선을 숨기기 위해 피부 alpha까지 뚫지 않는다. 내부 절단 경계를 모두
  둘러 그리지 않고 보이는 외곽선/필요한 안쪽 선만 그린다.
- 선 굵기·색은 원본에서 계측한다. 모든 선을 한꺼번에 다시 생성해
  자세에 따라 캐릭터의 선 스타일을 바꾸지 않는다.

## 정지 그림 검증과 수락

산출물은 원본 기본 / 새 기본, 원본 앉은 참고 / 새 앉은 자세의 비교,
부위별 독립 그림, 별도 관절 표시다. 흰색·어두운 배경과 실제96px 크기 및
확대 보기를 모두 제공한다. 큰 확대 그림만 보고 선의 선명도를 판정하지 않는다.

- 기본 그림: 머리 크기·기준점 동일, 원본 몸 윤곽·다리 비율 대조.
  새 벡터 몸은 AA/색 미세값까지 기존 RGBA와 동일하다고 주장하지 않는다.
  원본 외곽과1native-pixel 이내 일치를 초기 기술 목표로 삼되 시각 수락을
  대신하지 않는다. 다리 너비·길이·엉덩이 모양의 차이를 비교에 숨기지 않는다.
- 앉은 그림: 앞다리 두 개가 짧은 발끝만 남지 않고 곧은 지지대로 보이며,
  뒷발이 앞쪽에 드러나고 엉덩이가 둥글게 내려앉는다. 배가 땅에 눌린 모습은
  실패다. 머리로 몸의 비율 문제를 가리거나 머리 크기를 줄여 맞추지 않는다.
- 구조 검사: 부위 그림이 비어 있지 않고 모든 면이 닫혀 있는지, 관절·발바닥
  구분, 실제 자세 입력 반영, z순서/불투명 가림, 내부 연결부 구멍·겹친 선을
  확인한다. 검사 통과와 사용자 시각 수락은 별개로 기록한다.

모양이 다르면 정지 그림/관절 배치부터 수정한다. 코드 검사가 통과했다는
이유로 실패한 끝자세에 애니메이션을 연결하거나 설치본을 바꾸지 않는다.

## 이후 연결 범위

정지 자세 수락 후 별도 단계에서 앞다리 지지 → 뒷발을 들어 앞으로 뻗기 →
골반의 늦은 하강 → 작은 한 번의 안착을 관절 동작으로 연결한다. 일어서기는
별도로 검수한다. 이는 현재 첫 정지 산출물의 완료 조건을 확대하는 지시가 아니다.

## 검토 경계

최초 ‘ㄱㄱ’는 방향 승인, 설계서 제시 뒤 후속 ‘ㄱㄱ’는 이 문서 승인으로
기록한다. 계획 제시 뒤 추가 ‘ㄱㄱ’로 Native 정지 구현을 진행한다.
정지 그림의 시각 수락과 동작 연결 승인은 아직 별개다. 기존 실패한 로컬 도구/영상과 설치본은
그대로 보존하며, 문서 작성은 기술 해결·시각 수락·권리 허가를 의미하지 않는다.
