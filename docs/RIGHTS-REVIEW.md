## 현재 증거

사용자는 웹 검색으로 공식 이미지라고 생각한 자료를 받았으며, 원문 링크·작가·
허락 기록은 없다고 확인했습니다. 따라서 공식 게시물 여부와 동일 파일 여부는
미확인입니다. 검색 노출, 유사한 모습, 다른 무료 펫의 존재는 허가 증거로 삼지 않습니다.

검토 대상 대표 파일(SHA256):

| 파일 | SHA256 |
| --- | --- |
| `src/Dororong.App/Assets/dororong-canonical-source.png` | `F96EC30CBD18429E6BA1138BFA4EB44F331974C9820D36EE97A02FE518E46504` |
| `src/Dororong.App/Assets/dororong-canonical.png` | `699348D1973709F228D843341AC5312AA7F449D57B9BFC76576256231E259A78` |
| `src/Dororong.App/Assets/dororong.ico` | `E04E0121E5CE2B3BF3FCD9FCE79F286F6D8D7406FA7C72AA579297BD1D4362C6` |

그 밖의 파생 프레임도 같은 출처 검토가 필요합니다. PNG 및 압축 프레임을 앱 리소스로
내장하므로 느슨한 원본 PNG만 설치본에서 제외해도 이미지 재배포는 없어지지 않습니다.
코드 MIT와 .NET 라이선스 동봉은 별개이며 캐릭터 권리를 해결하지 않습니다.

## 공개 배포 전 필요한 근거

1. 실제 사용한 그림의 공식 출처 또는 권리자 및 파일 일치 확인.
2. 수정·애니메이션화·실행 파일 동봉·공개 Git 소스/ZIP 재배포 허용 범위.
3. 데스크톱 펫의 정책상 분류 또는 개별 예외 허가.

현 상태에서는 새 파일 공개를 보류하고 서면 확인을 받는 방안을 권합니다.
기존 공개판·공개 저장소·보관 브랜치도 동일한 이미지 문제를 검토해야 합니다.
최초 점검에서는 기존 파일을 변경하지 않았습니다. 이후 사용자 승인으로 저장소를
비공개로 전환했고, 커밋·태그 및 릴리스 2개의 자산은 보존했습니다. 대안은 권리가 확보된
독창적 캐릭터 사용 또는 이미지/아이콘/프리뷰를 제외한 코드 배포안의 별도 검토입니다.
